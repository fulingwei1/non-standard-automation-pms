# 面向类似费思泰克这类公司的垂直 Agents 方案

适用对象假设：
- 做测试电源、电子负载、电源测试系统、ATE/老化/验证平台、实验室与产线测试设备
- 客户以汽车电子、家电、新能源、电源模组、储能、工业电子为主
- 业务链条同时覆盖：售前、方案、研发、测试、交付、售后、量产支持

目标：
不是只做几个通用岗位 agent，而是做一套能覆盖“从商机到交付再到售后复盘”的行业型 agents。

---

## 一、建议先做 3 层架构

### 第 1 层：前台业务 agents
直接面向客户、项目、交付问题。

### 第 2 层：技术专业 agents
围绕测试电源、电子负载、控制、测量、可靠性、系统集成等专业环节。

### 第 3 层：经营管理 agents
围绕报价、成本、交付风险、产品规划、售后知识沉淀。

---

## 二、建议首批 16 个 agents

## A. 商机 / 售前 / 方案类

### 1. 测试设备售前解决方案经理
适合：客户初步沟通、需求整理、项目定性、商机推进
核心输出：
- 客户需求摘要
- 待确认项
- 风险点
- 推荐方案路径
- 报价前输入清单

### 2. 电源测试系统架构师
适合：系统级方案规划
核心输出：
- 系统拓扑
- 电源/负载/测量/控制/通讯架构
- 通道规划
- 扩展与冗余建议

### 3. 电子负载应用工程师
适合：电子负载选型、动态工况分析、应用边界定义
核心输出：
- 负载类型匹配
- CC/CV/CR/CP 工况建议
- 动态响应关注点
- 热设计与并机风险

### 4. 测试电源应用工程师
适合：测试电源方案、双向电源、回馈型应用场景
核心输出：
- 电源规格匹配
- 四象限/双向需求判断
- 精度、纹波、动态响应建议
- 安全保护策略

---

## B. 产品 / 技术研发类

### 5. 功率拓扑设计顾问
适合：Buck/Boost/LLC/DAB/回馈架构等拓扑分析
核心输出：
- 拓扑选型建议
- 效率/成本/复杂度取舍
- 功率器件风险
- 热与EMI注意事项

### 6. 控制算法与动态响应工程师
适合：控制环、动态负载响应、并机均流、稳定性分析
核心输出：
- 控制策略建议
- 动态响应分析
- 稳定性风险点
- 参数整定方向

### 7. 精密测量与校准工程师
适合：电压电流功率测量链、精度漂移、校准策略
核心输出：
- 测量架构建议
- 校准流程
- 误差预算
- 长期稳定性关注点

### 8. 测试软件与自动化平台工程师
适合：SCPI、上位机、自动测试脚本、报表系统、数据平台
核心输出：
- 软件架构
- 自动测试流程
- 数据采集与报表方案
- 接口规范建议

### 9. 可靠性与安规验证工程师
适合：老化、HALT/HASS、保护策略、安规合规
核心输出：
- 可靠性验证计划
- 失效模式清单
- 安规风险项
- 验证优先级

### 10. 热设计与结构实现工程师
适合：散热、风道、器件布局、结构约束
核心输出：
- 热路径分析
- 风冷/液冷建议
- 噪音/体积/散热取舍
- 布局风险

---

## C. 测试 / 交付 / 现场类

### 11. 样机调试与问题定位工程师
适合：样机阶段调试、故障复现、根因定位
核心输出：
- 故障定位思路
- 排查步骤
- 证据清单
- 临时措施与永久措施建议

### 12. 出厂测试与验收工程师
适合：FAT、出厂验证、验收脚本、交付前闭环
核心输出：
- 测试项目矩阵
- 验收标准
- 样机/量产机差异点
- 放行建议

### 13. 现场交付与联调工程师
适合：客户现场联机、系统集成、异常恢复
核心输出：
- 现场调试计划
- 接口联调清单
- 风险升级路径
- 交付问题清单

### 14. 售后服务与复发问题工程师
适合：客户投诉、现场问题、远程支持、复发问题沉淀
核心输出：
- 服务工单结构化摘要
- 故障分类
- 远程排障步骤
- 复发预防建议

---

## D. 经营 / 管理 / 产品类

### 15. 报价与成本风险分析师
适合：报价前风险识别、成本构成检查、毛利保护
核心输出：
- 成本敏感项
- 报价边界
- 高风险假设
- 交付风险与成本联动项

### 16. 产品规划与竞品分析经理
适合：产品线布局、对比致茂/ITECH/同类厂商、路线规划
核心输出：
- 竞品对比表
- 产品路线建议
- 差异化能力建议
- 中短期产品规划建议

---

## 三、如果只先做第一批，建议优先这 8 个

最值得先落地的 8 个：
1. 测试设备售前解决方案经理
2. 电源测试系统架构师
3. 电子负载应用工程师
4. 测试电源应用工程师
5. 测试软件与自动化平台工程师
6. 样机调试与问题定位工程师
7. 售后服务与复发问题工程师
8. 报价与成本风险分析师

原因：
- 这 8 个最直接影响接单、方案、交付、售后闭环
- 和你现有业务最贴近
- 先做出来就能直接提升日常工作效率

---

## 四、建议按业务链条组织，而不是按部门组织

推荐链条：

### 1. 商机阶段
- 测试设备售前解决方案经理
- 报价与成本风险分析师

### 2. 技术方案阶段
- 电源测试系统架构师
- 电子负载应用工程师
- 测试电源应用工程师
- 功率拓扑设计顾问

### 3. 研发实现阶段
- 控制算法与动态响应工程师
- 精密测量与校准工程师
- 测试软件与自动化平台工程师
- 热设计与结构实现工程师

### 4. 验证交付阶段
- 可靠性与安规验证工程师
- 样机调试与问题定位工程师
- 出厂测试与验收工程师
- 现场交付与联调工程师

### 5. 售后反哺阶段
- 售后服务与复发问题工程师
- 产品规划与竞品分析经理

---

## 五、每个 agent 都建议统一补这 6 类内容

每个 agent 建议包含：
1. Role Definition
2. Core Capabilities
3. Critical Rules / Operating Principles
4. Deliverables
5. Example Activation Prompt
6. Example Output Snapshot

如果要做成强一点的体系，再加：
7. Best Inputs
8. Common Failure Modes to Prevent
9. Handoff Package for the Next Agent

---

## 六、最适合你们公司的两种成套打法

### 方案 A：按“产品技术线”建 agents
适合你们如果产品型能力比较强。
例如：
- 电子负载
- 测试电源
- 测量校准
- 自动测试软件
- 功率拓扑
- 热设计

优点：
- 专业深度强
- 适合研发与产品团队

### 方案 B：按“业务流程”建 agents
适合你们如果更强调项目落地。
例如：
- 售前方案
- 系统架构
- 调试定位
- 验收交付
- 售后复发
- 报价成本

优点：
- 更容易直接落地到日常业务
- 对销售、项目、售后更友好

### 我的建议
对你们这种类型公司，最好是：
先按“业务流程”做第一批，
再补“产品技术线”作为第二批。

---

## 七、推荐你下一步的落地顺序

### 第一阶段
先落 4 个：
1. 测试设备售前解决方案经理
2. 电源测试系统架构师
3. 样机调试与问题定位工程师
4. 售后服务与复发问题工程师

### 第二阶段
再补 4 个：
5. 电子负载应用工程师
6. 测试电源应用工程师
7. 测试软件与自动化平台工程师
8. 报价与成本风险分析师

### 第三阶段
再补剩余深度技术 agent。

---

## 八、最短结论

如果是类似费思泰克这种公司，不建议只做“通用制造业 agents”。
更应该做一套偏“测试电源 / 电子负载 / 自动测试系统 / 交付售后闭环”的专属 agents。

最优路径不是一下做 16 个，
而是先做 4~8 个最贴近业务闭环的核心 agents，再逐步扩成完整体系。

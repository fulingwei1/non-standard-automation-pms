# 关键域分层（初版）

> 目的：在 `STRICT_API_ROUTER=true` 时保证核心交易链路安全；对低优先级功能可按需降级 warning。

## A. 必须 fail-fast（核心域）

- auth / users / roles / permissions / organization
- projects / production / sales / timesheet / approvals
- customers / suppliers / materials / purchase / bom / inventory / shortage
- acceptance / warehouse / notifications / issues / report / dashboard
- itr / service / scheduler / tenants

这些模块任一加载失败，应中止启动。

## B. 可降级 warning（候选）

- culture-wall / culture-wall-config
- business-support / business-support-orders
- pitfalls / lessons
- project-contributions / pm-involvement
- presale-ai-requirement / presale-mobile / presale-analytics
- strategy / ai-strategy / ai-modules
- solution-credits / management-rhythm / kit-check
- report-center（若主报表链路已独立可用）

这些模块若失败，可先警告并允许系统启动（需产品确认）。

## C. 执行建议

1. 先跑 `scripts/startup_regression_check.py --strict true` 获取真实失败模块。
2. 对失败模块按上面分层处理：
   - 属于 A：修复，不降级。
   - 属于 B：可临时降级 warning，但要挂修复工单。
3. 每周回顾 B 列表，持续收缩可降级范围。

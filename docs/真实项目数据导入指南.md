# 真实项目数据导入指南

## 概述

本指南说明如何将金凯博真实项目数据导入售前智能体系统，让AI能够基于真实案例生成更精准的建议。

## 为什么要导入真实数据？

当前系统中的案例数据主要是演示数据，导入真实项目数据后：

1. **AI建议更精准**：基于真实项目经验，而不是泛泛而谈
2. **报价更准确**：参考真实项目金额和周期
3. **案例更有说服力**：销售可以引用真实客户案例
4. **AI持续学习**：通过反馈机制不断改进

## 数据准备

### 1. 下载模板

模板文件位置：`scripts/projects_template.csv`

### 2. 填写数据

按照以下格式填写真实项目数据：

| 字段 | 说明 | 必填 | 示例 |
|------|------|------|------|
| project_name | 项目名称 | ✅ | 比亚迪BMS电池管理系统测试 |
| customer_name | 客户名称 | ✅ | 比亚迪 |
| industry | 行业 | ❌ | 新能源汽车 |
| project_amount | 项目金额（万元） | ❌ | 500 |
| project_duration | 项目周期（天） | ❌ | 180 |
| project_date | 项目日期 | ❌ | 2024-03-15 |
| project_type | 项目类型 | ❌ | BMS测试 |
| project_summary | 项目摘要 | ❌ | 为比亚迪开发BMS电池管理系统功能测试设备 |
| technical_highlights | 技术亮点 | ❌ | 采用FPGA+ARM架构实现高精度电芯模拟 |
| success_factors | 成功要素 | ❌ | 技术团队经验丰富；快速响应客户需求 |
| lessons_learned | 经验教训 | ❌ | 高压测试需要特殊安全防护 |
| customer_feedback | 客户反馈 | ❌ | 客户对测试精度和稳定性非常满意 |
| win_rate | 是否中标 | ❌ | 是 |

### 3. 数据要求

- **必填字段**：`project_name` 和 `customer_name` 必须填写
- **金额单位**：`project_amount` 使用万元，脚本会自动转换为元
- **日期格式**：`project_date` 使用 YYYY-MM-DD 格式
- **中文支持**：所有文本字段支持中文

## 常见问题

### Q: 导入失败怎么办？

A: 检查以下几点：
1. 文件路径是否正确
2. CSV格式是否正确（逗号分隔）
3. 必填字段是否完整
4. 日期格式是否正确

### Q: 可以重复导入吗？

A: 可以。脚本会自动检查重复，不会创建重复记录。

### Q: 导入后可以修改吗？

A: 可以。在系统中直接编辑项目/客户/案例信息。

### Q: 支持Excel格式吗？

A: 支持。将 `.csv` 改为 `.xlsx` 即可。
